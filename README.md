# El rosario en el teléfono

El objetivo es que quien quiera rezar el rosario pueda abrir un enlace desde su teléfono y encontrar los misterios de hoy sin tener que recordar qué día toca cada uno. La referencia para el contenido en español es [El Santo Rosario, del Vaticano](https://www.vatican.va/special/rosary/documents/misteri_sp.html).

## Cómo se usará

- **Rezar hoy.** Al abrir la página, lo primero que se verá será el día de la semana y los cinco misterios que le corresponden, en el orden en que se rezan. El día se determinará según la fecha local del teléfono.
- **Consultar todos los misterios.** Habrá un índice con los cuatro grupos y sus días: gozosos (lunes y sábado), dolorosos (martes y viernes), gloriosos (miércoles y domingo) y luminosos (jueves).
- **Leer un misterio.** Tanto desde «Hoy» como desde el índice se podrá abrir cada misterio y leer el texto más extenso que ofrece la fuente, no solo el título.
- **Aprender cómo se reza.** Una página dedicada explicará el rosario paso a paso, con el orden de las oraciones y el momento en que se anuncia cada misterio.
- **Configurar un recordatorio.** Quien lo desee podrá elegir a qué hora quiere recibir un aviso para rezar, cambiar la hora o desactivarlo. Si el teléfono requiere permiso para enviar notificaciones, se pedirá al activar el recordatorio.

## Lectura e instalación

La página se diseñará primero para pantallas pequeñas: texto legible sin ampliar, párrafos cómodos de leer y enlaces fáciles de tocar. Se podrá usar directamente desde el navegador, sin instalar nada, o instalar en la pantalla de inicio del teléfono para volver a ella cada día.
