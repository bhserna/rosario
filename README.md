# El rosario en el teléfono

[https://bhserna.github.io/rosario/](https://bhserna.github.io/rosario/)

El índice enlaza los misterios de hoy, los cuatro grupos y cómo se reza. «Misterios de hoy» abre el grupo que corresponde al día de la semana del teléfono. Cada misterio incluye la lectura del Vaticano. Después de la primera visita las páginas quedan guardadas y se pueden abrir sin conexión.

Los textos vienen de [El Santo Rosario](https://www.vatican.va/special/rosary/documents/misteri_sp.html).
